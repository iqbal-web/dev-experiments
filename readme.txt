== Description ==

Dev Experiments is a powerful WordPress plugin that adds a beautiful, customizable Gutenberg block to your editor. Built with modern development practices and AI assistance, this plugin demonstrates the best of block development.

= Features =

* **Custom Gutenberg Block** - Beautiful block with gradient backgrounds
* **Rich Text Editing** - Fully editable title and content
* **Inspector Controls** - Toggle features from the sidebar
* **Responsive Design** - Mobile-friendly and optimized
* **Color Support** - Customizable background and text colors
* **Spacing Controls** - Adjust padding and margin
* **Animated Icon** - Eye-catching pulse animation
* **Modern Development** - Built with @wordpress/scripts

== Installation ==

= Automatic Installation =

1. Log in to your WordPress admin panel
2. Navigate to Plugins → Add New
3. Search for "Dev Experiments"
4. Click "Install Now" and then "Activate"

= Manual Installation =

1. Download the plugin ZIP file
2. Log in to your WordPress admin panel
3. Navigate to Plugins → Add New → Upload Plugin
4. Choose the downloaded ZIP file and click "Install Now"
5. Activate the plugin

= After Activation =

1. Create or edit a post/page
2. Click the "+" button to add a new block
3. Search for "Dev Experiments Block"
4. Click to insert and start customizing!

== Frequently Asked Questions ==

= How do I use the block? =

After activating the plugin, edit any post or page. Click the "+" button to add a block, search for "Dev Experiments Block", and insert it. You can then customize the title, content, and settings.

= Can I change the colors? =

Yes! The block supports WordPress color controls. Select the block and use the color picker in the sidebar to change background and text colors.

= Is the block responsive? =

Absolutely! The block is fully responsive and includes mobile-specific optimizations for the best experience on all devices.

= Can I hide the icon? =

Yes, you can toggle the icon visibility using the "Show Icon" control in the block settings sidebar (Inspector Controls).

= How do I customize the block further? =

The block supports WordPress spacing controls (padding and margin). You can also edit the source code to customize styles, add features, or modify behavior.

= Is this compatible with Full Site Editing? =

Yes, the block works seamlessly with both the classic block editor and Full Site Editing (FSE) themes.

= Does it work with my theme? =

Yes! This block is designed to work with any properly coded WordPress theme that supports the block editor.

= Can I use multiple instances of the block? =

Yes, you can add as many instances of the block as you need on a single page or across your site.

= Is the plugin translated? =

The plugin is translation-ready and uses the 'dev-experiments' text domain. You can translate it using tools like Loco Translate or WPML.

= Where can I report bugs or request features? =

Please report issues or suggest features on our [GitHub Issues page](https://github.com/iqbal-web/dev-experiments/issues).
